# Task 1 - Data Cleaning and Preprocessing

## Objective

The goal of this project is to clean and preprocess a raw dataset using Python and Pandas.

## Dataset Used

Netflix Movies and TV Shows Dataset from Kaggle.

## Tools Used

* Python
* Pandas
* VS Code

## Data Cleaning Steps Performed

* Checked missing values
* Filled null values
* Removed duplicate rows
* Renamed column headers
* Standardized text values
* Converted date formats
* Verified data types

## Output

A cleaned dataset ready for analysis and visualization.

## Files Included

* data_cleaning.py
* cleaned_netflix_data.csv
* screenshots
* README.md

## Learning Outcome

Learned practical data cleaning and preprocessing using Pandas.
